# P1 安全事件记录：进程清理方式不当（已自纠）

**记录时间**：2026-09-18
**严重度**：高（方法本身违反项目红线；**历史影响未知，无法事后确证**）
**状态**：已停止使用，已替换为可验证的清理方式

---

## 1. 事件

在 P1/T01-3 与 T01-5 的多次试跑之间，为清理上一次实验残留的宿主进程，使用了：

```powershell
Get-Process acad,AutoLispDebugAdapter -ErrorAction SilentlyContinue | Stop-Process -Force
```

该命令以**进程名**为条件终止**所有**匹配进程，**不校验归属**。

## 2. 违反的红线

项目约束明确要求：**不得关闭用户的 CAD 进程**。
上述命令一旦在用户已打开 AutoCAD 时执行，会**无差别关闭用户会话**。

## 3. 实际影响（据实记录，不淡化）

| 项 | 事实 |
|---|---|
| 执行次数 | **不声称具体次数**（历史命令记录不完整，无法可靠计数） |
| 是否实际关闭了用户会话 | **未知，且无法事后确证**。进程归属与创建时间均未记录，因此无法重建当时是否有用户会话被终止。此前"未发现"的说法**已撤回**——"未发现"不等于"未发生" |
| 是否可能造成损害 | **是**。命令本身以进程名为条件终止所有匹配进程，任何时刻都可能关闭用户会话 |
| 是否有证据表明用户数据受损 | 未发现证据，但**未发现 ≠ 未发生**；本记录不对损害作任何否认 |

**结论：这是一个**已发生的安全缺陷**。它的严重性不取决于是否造成可见损害——
安全性当时来自"恰好没有用户 CAD 在跑"，而非来自命令本身。**不得**以"结果无害"为由轻描淡写，
也**不得**声称损害不存在。

## 4. 其他被同时指出的问题（一并自纠）

| # | 问题 | 处置 |
|---|---|---|
| 1 | 进程归属未验证（仅按安装目录匹配并取 `found[0]`） | 改为 **PID + 进程创建时间 + 可执行文件路径** 三重校验，且只清理本进程亲自启动并记录过的 PID |
| 2 | `win32com.client.Dispatch(progid)` 回退可能**启动或选中非预期实例** | **移除回退**。只允许 `GetActiveObject`；失败即判定为不可用，不得隐式启动宿主 |
| 3 | 用被遗弃的 COM 工作线程 | 改为**独立的受限子进程**，可被可靠终止，不留悬挂线程 |
| 4 | 声称 `ACAD_USERPROFILE` 提供隔离 | **撤回该声称**。该变量对 AutoCAD 用户配置目录的隔离效果**未经证实**；只能说"设置了该变量"，不能说"隔离了用户配置" |
| 5 | 报告中若干因果推断过强 | 见 §5，逐条降级 |

## 5. 报告中需降级的因果推断（逐条）

| 原表述 | 问题 | 修正后表述 |
|---|---|---|
| "COM 阻塞 ⇒ 插件 CommandMethod 不可能服务暂停期查询" | COM 超时**不能**证明所有插件执行路径都不可能；空快照提示阻塞可能发生在**建立 COM 连接**阶段，而非数据库读取阶段 | "观察到的现象是：暂停期经 COM 读取未返回。这**不足以**排除其它插件侧机制（例如受支持的只读回调），该机制尚未验证。" |
| "`repl` 求值被推迟到 continue 才执行" | **不成立**。`sync-read-forms.json` 显示 `3.0` 出现在 resume **之前**；早前脚本只是**事后**才去收集累积输出 | "`repl` 求值的返回值不是即时可用的：调用当时 `result` 为空。其**确切时序未确定**。" |
| "`watch` + `frameId` 必然导致崩溃" | 该组合出现于一次已被污染的混合实验；之后同会话中的成功不能反证安全 | "在一次混合实验中，`watch` + `frameId` 之后观察到访问冲突（0xC0000005）。**因果未确立**，仅作为危险关联记录，暂不使用该组合。" |
| "`processId` 必须是字符串 / `type` 必须是 `attachlisp` / 超时不足" | 三者**同时**改动，未单独验证 | "将 `processId` 改为字符串、`type` 改为 `attachlisp`、并延长超时后，attach 成功。**三者各自的必要性均未单独证明。**" |
| "`P=nil` 说明帧缓存陈旧" | 与"在 `setq` 完成前停止"一致，非陈旧证据 | "stepOut 后 `P` 为 `nil`，与"停止发生在包含它的 `setq` 完成之前"一致。不作为陈旧性证据。" |
| "断点 6 与 8 同时生效" | 两次**分别**的 `setBreakpoints` 请求会**替换**该源的断点集 | "两个断点必须在**同一次** `setBreakpoints` 请求中提交；分两次提交时后者替换前者，这解释了当时只命中第 8 行。" |

## 6. 立即生效的新规则

1. 清理只允许针对**本进程启动并登记**的 PID，且清理前重新校验 `CreationDate` 与 `ExecutablePath`。
2. 禁止任何形式的按名终止（`Stop-Process -Name`、`taskkill /IM`）。
3. 禁止 `Dispatch` 回退；只允许 `GetActiveObject`。
4. 不再声称 `ACAD_USERPROFILE` 提供隔离。
5. 在安全审查通过前，**暂停新的真机 CAD 实验**。
